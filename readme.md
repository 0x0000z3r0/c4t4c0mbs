The hacker catacombs for learning low-level firmware and hardware security.

## Dependencies

For the RTOS/RISC-V labs, you will need the following dependencies:
```bash
sudo apt-get update
sudo apt-get install -y gcc-riscv64-unknown-elf qemu-system-misc picolibc-riscv64-unknown-elf
```

Don't forget to clone with submodules (or initialize them later):
```bash
git submodule update --init --recursive
```
